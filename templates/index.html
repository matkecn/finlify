            About Finlify

            A local-first personal finance dashboard that treats your money with exact arithmetic and never phones home.

            Source API docs Export data

            Exact money

            Every amount is stored and summed as integer cents and only turned into decimals for display, so balances never drift.

            Local first

            FastAPI and SQLite run on your own machine. No accounts, no telemetry, no network calls — just one database file you own.

            Zero dependencies

            The charts are hand-drawn on canvas, so the interface pulls in nothing from a CDN and works completely offline.

            Yours to keep

            Export a versioned JSON backup at any time and restore it losslessly, on this machine or another one.

            Stack
            FastAPI · SQLite · Jinja2 · vanilla JS
            Money model
            Integer cents, half-up rounding
